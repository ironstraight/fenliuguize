## Current shared behavior

- The three subscription projects use the same `subscription-transform.js` implementation.
- Multiple URL input accepts line breaks or `|` without requiring spaces around the separator.
- Persistent global exclusion processes original node names before per-source numbering.
- Source names use `Source Name|Region|001`; a duplicate region is not appended, and an unrecognized region produces `Source Name|001`.
- A blank source name preserves the original node name unless a separate global rename rule is configured.
- One-time subscriptions do not write KV and do not require the unlock password; only “添加到部署阵列” persists data.
- When all temporary inputs are blank, “一键复制订阅” returns the persistent default subscription.
- The same URL defaults to Clash/Mihomo YAML; distinctive v2rayN/sing-box User-Agents or an explicit `format` query choose share-URI or JSON output. A converter lacking that target yields an error, not mislabeled content.
- Protected “添加到部署阵列” can save filled global RENAME/exclusion or custom backend/preset fields without a new URL. Blank fields preserve existing global values, and subsequent source additions do not erase them.
- With URL input, one-click copy uses only temporary sources. With no URL but temporary rules or custom converter fields, it signs a temporary link that reads the persistent sources; no KV write occurs in either case.
- Adding a persistent source and entering the management view require the advanced password. Solidifying edits in an already unlocked management view does not prompt again.
- Successful converted profiles use a stable configuration fingerprint: fresh cache hits return immediately and older successful profiles may be served while a bounded background refresh runs. A bounded last-known-good copy in existing `MY_KV` helps cold colos after the first successful conversion, but cannot guarantee first-request availability when the source or converter is down.
- User-entered source URL paths are preserved. Quota notices and other source node names are never automatically excluded; the user controls exclusions and production data in the frontend.
- Each subscription card displays only its URL and source name; global rules appear once below the list.
- asub owns its Water-theme assets and does not depend on the EthanSub hostname.
- The shared OpenClash/Mihomo base uses encrypted foreign default DNS with explicit domestic policy; optional OpenClash and ClashMi/Mihomo capture artifacts are documented in `DNS_LEAK_PROTECTION.md`.
